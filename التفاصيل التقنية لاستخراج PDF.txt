الدوال الرئيسية:
═════════════════

1. handleAcPdf(input)
   • الغرض: معالجة رفع ملف PDF
   • المدخلات: HTML input element
   • المخرجات: تحديث S.acPdfFile و S.acPdfUrl
   • الاستخدام: عند اختيار ملف PDF من الكمبيوتر

2. extractAndGenerateFromPdf()
   • الغرض: استخراج النص وتوليد الأسئلة
   • المدخلات: لا توجد (تستخدم S.acPdfFile من الكائن العام)
   • المخرجات: يملأ حقل ac-content ويستدعي genAllContent()
   • الاستخدام: عند الضغط على زر ⚡ استخراج وتوليد
   // الخطوات:
   // 1. التحقق من وجود ملف PDF
   // 2. قراءة البيانات الثنائية
   // 3. استخراج النص من كل صفحة
   // 4. تنظيف وحفظ النص
   // 5. حفظ المحتوى
   // 6. استدعاء genAllContent()

3. extractAndGenerateFromPdf()
   • الغرض: استخراج النص فقط
   • المدخلات: S.acPdfFile
   • المخرجات: يملأ حقل ac-content بالنص المستخرج
   • الاستخدام: عند الضغط على زر 🔄 استخراج النص
   // الفرق:
   // لا تستدعي genAllContent()
   // تترك للمستخدم الخيار للمتابعة يدوياً

4. genFromPdfUrl(modId, itemIdx, pdfUrl)
   • الغرض: استخراج من URL PDF موجود
   • المدخلات: معرّف المحاضرة ورابط PDF
   • المخرجات: محتوى مستخرج + أسئلة مولدة
   • الاستخدام: من عرض المحاضرة (زر ⚡)
   // يختلف عن الدوال السابقة:
   // - يستخدم fetch() للحصول على الملف
   // - يستخرج النص مباشرة
   // - يستدعي genAllContent()

معالجة الأخطاء:
═══════════════

```javascript
try {
    // محاولة استخراج من PDF
    const arrayBuffer = await S.acPdfFile.arrayBuffer();
    const pdf = await pdfjsLib.getDocument({data: arrayBuffer}).promise;
    // معالجة كل صفحة
    for(let i=1; i<=maxPages; i++) {
        const page = await pdf.getPage(i);
        const textContent = await page.getTextContent();
        // جمع النص
    }
} catch(e) {
    // معالجة الخطأ
    notify("خطأ في الاستخراج: " + e.message);
    console.log("Error:", e);
}
```

الأخطاء المحتملة:
• ملف PDF محمى
• صيغة ملف غير صحيحة
• عدم دعم المتصفح
• PDF كبير جداً
• ملف تالف
