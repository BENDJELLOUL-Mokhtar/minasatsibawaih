🔑 شرح تحديث مفتاح API
════════════════════════════════════════════════════════

لتفعيل توليد الأسئلة بنجاح، يجب تحديث مفتاح API

خطوات الحصول على المفتاح:
═══════════════════════════

1️⃣ الذهاب إلى موقع Anthropic
   ─────────────────────────
   URL: https://console.anthropic.com/

2️⃣ تسجيل الدخول أو إنشاء حساب
   ────────────────────────────
   • البريد الإلكتروني
   • كلمة السر
   • التحقق من البريد

3️⃣ الذهاب إلى قسم API Keys
   ───────────────────────
   • في الجانب الأيسر: "API Keys"
   • أو زيارة: https://console.anthropic.com/keys

4️⃣ إنشاء مفتاح جديد
   ────────────────
   • اضغط "Create Key"
   • أعطه اسم: "Sibawayh Platform"
   • اضغط "Create"

5️⃣ نسخ المفتاح
   ──────────
   • المفتاح سيبدأ بـ: sk-ant-
   • انسخ المفتاح بالكامل
   ⚠️ لن تتمكن من رؤيته مرة أخرى!

═════════════════════════════════════

تحديث الكود:
═══════════

في ملف: index (8).html
البحث عن: الخط 1489

الكود الحالي:
```javascript
"x-api-key":"your-api-key-here",
```

الكود بعد التحديث:
```javascript
"x-api-key":"sk-ant-YOUR_ACTUAL_KEY_HERE",
```

مثال:
```javascript
"x-api-key":"sk-ant-abc123def456ghi789jkl012mno",
```

═════════════════════════════════════

الطريقة السهلة للتحديث:
═════════════════════

1. افتح الملف: index (8).html
2. اضغط: Ctrl + F (البحث)
3. اكتب: your-api-key-here
4. استبدل بـ: مفتاحك الحقيقي
5. احفظ: Ctrl + S

═════════════════════════════════════

التحقق من النجاح:
═════════════════

بعد تحديث المفتاح:

1. إعادة تحميل الصفحة
   • Ctrl + Shift + Delete (لحذف الكاش)
   • ثم Ctrl + R (لإعادة التحميل)

2. اختبار التوليد
   • اذهب إلى المقررات
   • اختر محاضرة
   • رفع PDF
   • اضغط ⚡ استخراج وتوليد
   • انتظر النتائج

3. مراقبة الـ Console
   • اضغط F12 في المتصفح
   • اذهب إلى Console tab
   • تفقد الرسائل

═════════════════════════════════════

رسائل الخطأ وحلولها:
═══════════════════════

❌ "401 Unauthorized"
   ← المفتاح خاطئ أو منتهي الصلاحية
   ✅ تحقق من صحة المفتاح

❌ "429 Too Many Requests"
   ← تجاوزت حد الطلبات
   ✅ انتظر بضع دقائق قبل المحاولة

❌ "Invalid response format"
   ← هناك مشكلة في الاستجابة
   ✅ تحقق من رسائل الكونسول

❌ "API Error"
   ← خطأ عام من API
   ✅ تحقق من حالة Anthropic
